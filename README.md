# Atlas Store

Frontend-only e-commerce site (React + Vite + Tailwind CSS v4) replicating the layout,
typography and interactions of the "Atlas" Framer template with placeholder content.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build
```

See `CLAUDE.md` for project rules and `docs/DESIGN_NOTES.md` for the extracted design system.
